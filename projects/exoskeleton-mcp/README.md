# exoskeleton-mcp

An MCP server that compensates for the tool-mechanics failures of very small coding models:
anchored fuzzy editing, fuzzy path resolution, a structural repo jail, repeat-call detection,
and state echo on every result.

Status: design stage — nothing built yet. The design, its mapping to the failure taxonomy, and
the open questions live in `vault/dev/exoskeleton-mcp-design.md`. The failure taxonomy it is
built against is documented in `vault/docs/failure-taxonomy.md`.
